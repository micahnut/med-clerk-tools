# Med Clerk Tools

A minimal local-first composer for formatting OB-GYN and pediatric clinical updates as plain text for Viber or Messenger.

## Use

- Choose OB-GYN or Pedia.
- Fill the form and review the live text preview.
- Copy the message and paste it into your messaging app.

Entries are held in page memory only. The app does not save, upload, or transmit form contents. Clear the form or close/reload the page to remove the draft.

The OB-GYN and Pedia outputs follow the sample headings and order provided. Both are plain text for review and copying before sending.

## Local development

```sh
npm install
npm run dev
```
